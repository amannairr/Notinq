# Machine Learning: Gradient Descent and Neural Networks

Machine learning systems improve by adjusting parameters based on data.
Gradient descent minimizes loss by taking steps in the direction of the steepest decrease.
Neural networks use layers of weighted connections and are trained with backpropagation.
Key concepts:
- machine learning
- gradient descent
- loss function
- neural networks
- backpropagation

Relationships:
- gradient descent optimizes loss functions
- backpropagation computes gradients for neural networks
- neural networks are trained with gradient-based methods
