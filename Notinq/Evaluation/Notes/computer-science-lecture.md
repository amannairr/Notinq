# Computer Science Lecture

Binary search tree operations rely on ordered traversal, recursion, and balancing tradeoffs. The professor compared AVL trees with red-black trees and emphasized that search is logarithmic when the tree remains balanced. The lecture also covered amortized analysis for dynamic arrays and how recursion depth affects stack usage.
